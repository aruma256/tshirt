# nazo_find メモ

## 仕掛け
「D の中に F が入っている」＝ **"F in D" → FIND**。
下部に `Find the answer.` を表示。全体で **"find the answer."** と読める。

> 旧方針: かつては `Find` を独立した4本の下線（`____`）で伏せ、答えが4文字（find）
> であることを示していた。現在は **伏せずに `Find the answer.` をそのまま出力し、
> 出力後にペイントツールで手動加工する**方針に変更した。

## 構図
- 中央に大きな**中抜きの D**（輪郭線のみ）。
- D の中に小さな **F**。その右下に**虫眼鏡**を重ね、「F を見つける」を表現。
- レンズ内の F には**膨張歪み**（虫眼鏡で見たときの“拡大感”）をかけ、レンズらしさを出す。
- 虫眼鏡は **リング ─ 細いネック ─ 太い持ち手** の構造（実物寄り）。
- 下に `Find the answer.`（伏せ字なし。伏せる場合は手動加工）。

## 実装
- `nazo_find.py` — Python + PIL（他の nazo と揃えた）。冒頭パラメータで全体が連動。
- アンチエイリアス: PIL の図形描画（ellipse/line/rounded_rectangle）は AA されないため、
  内部を `SS` 倍で描画し最後に 1/SS へ LANCZOS 縮小（スーパーサンプリング）。これで
  虫眼鏡・下線・レンズ歪みにもまとめて AA がかかる。改善は SS=1→2 が大きく、2→4 は微小
  （diminishing returns）。コスト目安: SS=2 ≈ 7秒、SS=4 ≈ 23秒・ピーク約9.8GB（処理は SS²）。
  高 SS では巨大グリフの一時画像が PIL の圧縮爆弾上限を超えるため、冒頭で
  `Image.MAX_IMAGE_PIXELS = None` を設定して解除している（画像は自前生成で安全）。
- bulge は全画素を float 化せず「レンズ周辺の小領域のみ」float 化して省メモリ化済み
  （`src_d <= d` でサンプル点が必ず半径内に収まる性質を利用）。SS を上げても軽い。
- 中抜き D は `render_glyph()` で `fill=透明 + stroke` を使い、輪郭のみ描画（内部は透過）。
- 虫眼鏡: ネックは butt cap の直線で内側端をリング枠内に収め、レンズへの食い込みを防止。
  `MAG_HANDLE_GAP`（ネック長）/ `MAG_NECK_W`（ネック太さ）で調整可。
- レンズの大きさは F サイズと独立（`MAG_LENS_R`・px絶対値）。中心は F に追従するが、
  `F_FONT_SIZE` を変えてもレンズは不変。現状 F=300 でレンズ内に小さく収まる。
- レンズの膨張歪みは `apply_lens_bulge()`（numpy）。出力→元の逆写像＋バイリニア補間で
  円内のみ再サンプル。正規化半径 d に対し `src_d = s*d + (1-s)*d^3`（s=1/倍率）で、
  中心は一様に拡大・リムで圧縮（樽型）。d=1 で恒等となり円外と継ぎ目なく連続。
  強さは `MAG_BULGE`（中心倍率, 既定2.45）。リング枠／持ち手は歪みの後に上描き。

## メモ
- フォントは **Source Han Serif JP**。当環境は未インストールのため、同一書体の
  **Noto Serif CJK JP**（index 0）を使用（字形一致）。
- 検討用に背景は不透明白（`BG_COLOR` 末尾255）。**入稿時は `(0,0,0,0)`（透明）に戻す**。
- 色は黒。Tシャツ地色によって反転を検討。
