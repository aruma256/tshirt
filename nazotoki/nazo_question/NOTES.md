# nazo_question メモ（ラフ v0）

## 仕掛け
英単語 **question** の *部分アナグラム* が **seitou（正答）** と読める。
（`question` = q,u,e,s,t,i,o,n から **s,e,i,t,o,u** を取り出して並べ替えると seitou）

## このスクリプトの担当
作品の鍵となる「**？**」マーク上部の **フック（カール）状の部分** を、
**美しく＝バランスよく 7 等分**して描く。`nazo_question.py`。

## 7 等分の考え方（重要）
フックを「**centerline（ペン先が通る軌跡）に太さ W を掃いたリボン**」とみなす。
- **何で割るか**: centerline の **弧長を 7 等分**。各ピースはペンが進む長さが等しい。
  太さ一定なら 7 ピースは面積もほぼ等しく、最もバランスが取れる（＝「美しい」）。
- **どう切るか**: 「縦・横」で切らず、各切れ目を centerline の **接線に直交** させる。
  これが「**書く線に沿って切る**」＝リボンの真横を切る断面。切れ目の向きは曲がりに追従する。

→ centerline を弧長でパラメータ化し、`k/7`（k=1..6）の位置で接線直交の切れ目を入れる。
  全弧長 L ≈ 2098px、1 ピース ≈ 300px（SS=1 換算）。

## 実装
- フォントは使わず、フックを **制御点 → Catmull-Rom 補間** のパラメトリック曲線で作る
  （弧長を厳密に扱え、等分が正確。font グリフの medial axis 抽出を避けられる）。
- 「？」らしさ: 制御点は書き順（左上→頂点→右上→右→右下→底→末端）で、**左下が開いた
  フック形**、末端は中央で下を向く（ドット／ステムへ続く向き）。`CONTROL_POINTS` で調整。
- 等分: 全サンプルの累積弧長 `s` を作り、境界 `L*k/7` で点と接線（中央差分）を求める。
  切れ目は接線直交の細長い長方形を **背景色**で重ねて入れる（`SLIT_W` / `SLIT_MARGIN`）。
- 太さ: `STROKE_W` 一定（`WIDTH_MOD>0` で中央を太らせる変調も可。一定が最もバランス良い）。
- アンチエイリアス: 内部を `SS` 倍で描き最後に 1/SS へ LANCZOS 縮小。v0 は SS=3。
- 出力 2 種:
  - `nazo_question.png` … 本番（黒・切れ目で 7 分割）。
  - `nazo_question_debug.png` … 検証用（7 ピースを色分け＝等分の目視確認）。
