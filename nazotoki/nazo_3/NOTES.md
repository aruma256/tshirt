# nazo_3 メモ

## テーマ
太陽系 — 内側の天体（太陽・水星・金星・地球・月）を並べる。

## 仕掛け
惑星名（すいせい・きんせい・ちきゅう・つき）の中に「い・ん・せ・き」（隕石）が散らばっている。
- ① = い
- ② = ん
- ③ = せ
- ④ = き
- 上記以外のかな = ◯

各天体名の置換結果:
| 天体 | かな | 表示 |
|------|------|------|
| 水星 | すいせい | ◯①③① |
| 金星 | きんせい | ④②③① |
| 地球 | ちきゅう | ◯④◯◯ |
| 月   | つき     | ◯④   |

解は「隕石」。

## 構図
- 左端に **太陽**（巨大すぎるので右端だけ見切れて見える、ほぼ画面外）
- そこから右へ **水星 → 金星 → 地球（＋月）** を並べる
- 各惑星には **公転軌道の弧**（太陽中心の円弧）と、惑星の縁から**右上45度に伸びるラベル**。
  ラベルは「素の7セグ数字」と「■（空欄）」を45度回転して斜めに並べる（リード線の流れに乗せる）
- 月は地球を**周回軌道（円）付き**で配置。右下35度に置き、ラベルが地球ラベルと重ならないようにする

イメージ:
```
                  １              １
                ３              ３
              １              ２            ◆ ← 45度に傾けた斜めラベル
            ◆              ４          ◆ ◆
 )      ●(水)         ●(金)        (◯地)  ◆４ ← 月ラベル
                                    ＼_／ ← 月の周回軌道＋月
```

## 比率方針
- **惑星・月の直径比は忠実**（地球=1、水星=0.3825、金星=0.9489、月=0.2724）
- **惑星間の距離間隔は実値比で配置**（水星0.387 / 金星0.723 / 地球1.0 AU）。
  外側ほど間隔が詰まる現実の特徴が出る。地球を x=`EARTH_X` に固定してスケールを逆算。
- **距離の起点は太陽の“描画上の表面”**。太陽を実比より大きく描いているため、
  中心から実比で測ると水星が巨大な太陽にめり込む。表面起点なら惑星間の間隔比は実値のまま保てる。
- **太陽だけは直径も視覚優先で縮小**。実比は109.1251倍だが、それだと
  (1) 巨大な「壁」になり、(2) 太陽中心の公転軌道弧の半径が大きすぎてほぼ直線になる。
  距離と同じ理屈で縮める。`SUN_VISUAL_RATIO`（現状=12）で調整。実比は `SUN_TRUE_RATIO` にメモ。
- **月の公転半径は2スケールの幾何平均**。月-地球(384,400km)はどのスケールでも破綻する
  （距離スケール≈6px / 直径スケール≈6000px）。両者の幾何平均＝対数中点 ≈188px を採用。
  目分量を避け一意に決まる根拠付きの値（`MOON_ORBIT_R` をコード内で両スケールから算出）。

## 実装
- `nazo_3.py` — Python + PIL（他のnazoと揃えた）
- ラベルは「素の7セグ数字」＋「■（塗りつぶし正方形＝空欄）」を**45度回転**して斜めに並べる。
  以前は丸＋丸数字だったが、惑星の円と相性が悪く混同するためやめた。
  各文字を透明タイルに描いて回転→`img.alpha_composite` で合成（`LABEL_ANGLE` / `LABEL_CHAR_PITCH` / `LABEL_LEAD_LEN` / `LABEL_SQUARE_SIZE`）。
  ※■も回転するので空欄は◆（ひし形）になる
- 太陽は塗りつぶし円のままだと巨大すぎてメモリを食うので、可視部分のみポリゴンで描画
- 軌道・太陽の弧は y を走査して x を計算する折れ線で描く（draw.arc だと巨大bboxになるため）

## 現状の懸念 / TODO（要相談）
- 太陽を視覚優先で縮小（SUN_VISUAL_RATIO=12）。右端カーブが出て軌道も弧になった。倍率は要微調整
- ラベルを45度回転＋斜め配置にして、リード線の流れに乗せた
- 月は周回軌道（円）付きで地球の近くに。公転半径は幾何平均で根拠付け（上述）
- 地球の周辺（月の軌道・月ラベルのリード線・地球の公転弧）がやや密集 → 要最終確認
- 検討用に背景を不透明白(`BG_COLOR`末尾255)にしてある。入稿時は0（透明）に戻す
- 月のラベル位置（地球のラベル列と別の高さ）が浮いて見える可能性 → 配置調整候補
- 線の太さ、ラベル円のサイズ、惑星と円の視覚的バランス
- 色（今は黒/透明背景）。Tシャツ地色によって反転検討
